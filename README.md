# СӨХ-ийн бүртгэлийн систем

Сууц өмчлөгчдийн холбооны оршин суугч, машин, зогсоолын бүртгэлийг нэг дор хөтлөх веб систем.

Хичээл: Программ хангамж хөгжүүлэлтийн процесс — Scrum аргачлалаар хийж буй багийн төсөл.

## Багийн гишүүд

| Гишүүн | Scrum үүрэг |
|---|---|
| Д.Ууганбаяр | Product Owner, Developer |
| [2-р гишүүний нэр] | Scrum Master, Developer |

Баг 2 хүнтэй тул үүргийг давхарлан гүйцэтгэнэ. Product Owner нь шаардлага тодорхойлж, Backlog-ийн эрэмбийг гаргана. Scrum Master нь Sprint-ийн уулзалтуудыг зохион байгуулна. Код бичих ажлыг хоёулаа хийнэ.

## Төслийн зорилго

СӨХ ихэвчлэн оршин суугч, машин, зогсоолын мэдээллээ дэвтэр, Excel дээр тусад нь хөтөлдөг. Иймээс хэн аль зогсоолыг ашиглаж байгаа, гадны машин орсон эсэхийг шалгахад хүндрэлтэй байдаг.

Энэ систем дараах ажлыг гүйцэтгэнэ:

- сууц, оршин суугч, машины бүртгэлийг нэг дор хөтлөх;
- зогсоолыг хүсэлт ирсэн дарааллаар хуваарилах;
- харуул улсын дугаараар машиныг шалгах;
- сарын төлбөрийг QPay-ээр хүлээн авах.

## Хэрэглэх технологи

- Frontend, backend: тодорхойлно
- Өгөгдлийн сан: тодорхойлно
- Version control: Git, GitHub
