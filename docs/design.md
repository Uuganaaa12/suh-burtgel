# Загвар — юзкейс ба ER диаграм

Энэ хуудсанд шаардлагын шинжилгээний үр дүнд гарсан загваруудыг нэгтгэв. Sprint-ийн story хэрэгжүүлэхдээ хүснэгт, талбарын нэрийг эндээс авч, ижил нэршил хэрэглэнэ.

Хэрэглэгч: **оршин суугч** (гар утас), **СӨХ-ийн менежер** (вэб). Гадаад систем: **банкны апп**.

## 2. Өгөгдлийн сангийн загвар

![ER диаграм](img/ERD.png)

| Хүснэгт | Хадгалах мэдээлэл | Холбогдох story |
|---|---|---|
| Хэрэглэгч | Gmail хаяг, утас, үүрэг (оршин суугч, менежер) | US-01, US-02 |
| Сууц | Байр, орц, давхар, тоот, талбай, сууцны код, оршин суугч | US-02, US-14 |
| Зогсоол | Дугаар, байршил, өмчлөлийн төрөл (дундын, хувийн), төлөв (сул, санал болгосон, түрээслэгдсэн, түр хаасан) | US-03, US-10 |
| Машин | Улсын дугаар, марк, өнгө, төлөв (идэвхтэй, цуцлагдсан), цуцалсан шалтгаан, бүртгүүлсэн огноо | US-04, US-05 |
| Зогсоолын түрээс | Хүсэлт гаргасан машин, хүсэлтийн огноо, хугацаа (сараар), санал болгосон огноо ба хариу өгөх хугацаа, эхлэх ба дуусах огноо, төлөв | US-05, US-06, US-07, US-08, US-10 |
| Нэхэмжлэх | Сар, хураамж, түрээсийн төлбөр, алданги, үүссэн огноо, төлөх хугацаа, төлөв | US-12, US-13, US-14 |
| Төлбөр | Төлсөн дүн, огноо, банк, гүйлгээний дугаар | US-13, US-14 |
| Мэдэгдэл | Хэрэглэгч бүрд очсон мэдэгдлийн агуулга, огноо, уншсан эсэх | US-05, US-10, US-12 |

Хураамж, түрээсийн үнэ, алдангийн хувь, төлөх өдөр, машины дээд тоо, санал баталгаажуулах хугацаа (48 цаг) өгөгдлийн санд биш, тохиргооны файлд хадгалагдана. Үнэ өөрчлөгдөхөд програмын код өөрчлөгдөхгүй.

Хоёр дүрмийг өгөгдлийн сангийн түвшинд хангана: сууцны код ба машины улсын дугаар давхардахгүй, нэг зогсоолд нэгэн зэрэг зөвхөн нэг санал эсвэл идэвхтэй түрээс байна.

Хүлээлгийн жагсаалтад тусдаа хүснэгт байхгүй. Зогсоол оноогдоогүй, «дараалалд» төлөвтэй хүсэлтийг хүсэлтийн огноогоор эрэмбэлэхэд дараалал гарна. Зогсоол сул болмогц систем дарааллын эхний хүсэлтэд санал болгож, оршин суугч 48 цагт баталгаажуулна. Менежер ердийн олголтод оролцохгүй, машины бүртгэлийг батлахгүй: гомдол ирвэл бүртгэлийг шалтгаантай цуцалж, засвартай зогсоолыг түр хаана. Өмнө зогсоол түрээсэлсэн эсэх эрэмбэд нөлөөлөхгүй.
